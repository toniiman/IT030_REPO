CSS,Cascading Style Sheet, is Cascading Style Sheet is used to style and lay out web pages, altering the font, color, size etc in a website in which the code observes the following rules:

  • If the two selectors are identical, the latter of the two will take precedence.
  • If one selector is more specific than the other, the more specific one takes precedence.
  • One can add !important after any property/name/key to indicate it should be more important than the other rules.
